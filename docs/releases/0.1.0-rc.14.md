# Music Index Studio 0.1.0-rc.14

This candidate gives a new user the Welcome page, with a default file host ([ADR 0119](../adr/0119-a-new-user-starts-as-a-musician-or-a-label.md), [ADR 0122](../adr/0122-a-new-user-starts-with-a-default-file-host.md)). The page of a person gets Save and Discard, "Find on musicindex" and the credit of a member ([ADR 0116](../adr/0116-the-page-of-a-person-has-save-and-discard.md) to [ADR 0118](../adr/0118-member-of-offers-a-credit-on-the-artist-feed.md)). The check of a person shows each difference ([ADR 0120](../adr/0120-the-check-of-a-person-shows-each-difference.md)). It comes after 0.1.0-rc.13.

## What changed

### The Welcome page

- A user with no feed sees "Welcome to Studio", and not the empty Releases page. The rows are **I make music**, **I run a label** and **My music is online already**.
- **I make music** and **I run a label** open a sheet with three steps: the name, "Where it lives", then the first album or the first artist.
- Step 2 always shows, and you cannot make the first page without a file host. On the desktop, **Folder on this computer** is selected at the start, with the folder `~/musicindex/pages`. Studio makes the folder when you continue.
- On a server, **Try it here (temporary)** is selected at the start. The server keeps the files of this area for 7 days after its last write. Then it deletes them, and each feed of the area shows "The temporary area has expired. Move this feed to a real file host." The feeds and their drafts stay.
- With a connected file host, step 2 also shows a menu of your file hosts.

### Placeholder GUIDs and addresses

- A feed on a file host with no public address gets a placeholder GUID: `pending-` and a random ID. **Feed facts** tells why Studio cannot make the GUID at this time.
- Each song and image of such a feed gets a placeholder address: `pending:` and its path. The track page tells why, and the player plays the file from Studio. The write puts the files on the file host.
- When the feed gets a public address, Studio sets the real GUID and the real address of each file. This occurs when you move the feed to a file host with a public address, or when you give its file host a public address. Studio also changes the links between your pages, in the drafts and in the written feeds. You then write each changed feed through **Review**.
- The OP3 switch stays off until the feed has a public address.

### The page of a person

- The fields and the menus of the page of a person are pending changes until you select **Save**. **Discard** puts back the saved values. Save writes no feed.
- When you go from the page with a pending change, Studio asks first.
- **Find on musicindex** searches the publisher feeds of musicindex for the person. The rows have three levels: "Verified role", "Verified two-way links" and "Name only". A row gives the picture, the information address, the wallets and the Nostr key of the feed. Select the values, then **Fill**, then **Save**.
- After you set **Member of** and select Save, Studio offers to add the person to the credits of that artist or label feed. You review the change before Studio writes it. The page of an artist or label feed has the section **Members**.
- **Check your releases** shows each difference in its own entry. The entry gives the position, the value in the feed and the value of the person.
- **Use {name}'s Values** corrects that one feed.

### Other changes

- The page of an artist, label or hosting feed shows the role first.
- **Remove from Collection** is no longer in the entry **Feed facts**.
- When the player cannot play a file from its host, the error says that a browser setting can stop audio from other sites.
- A download no longer opens a different page in the tab.

## What to test

1. On the server, make a new account. Select **I make music**, then **Try it here (temporary)** in step 2.
2. Make sure that **Feed facts** gives a GUID that starts with `pending-`, with the text that tells why.
3. Add an album with two songs, and write the album and the artist page.
4. Add your real file host, and move the album and the artist page to it. In Review, make sure that each GUID and each song address changes, and that each link names the new GUID.
5. Write the two feeds. Open each feed address in a new tab, and make sure that it has no `pending` text.
6. On the page of a person, change a field, then select **Discard**. Change it again, and select **Save**.
7. Select **Find on musicindex**, fill a value, and select Save.
8. Set **Member of**, select Save, and review the credit.

## Known gaps

- A write with a show grant does not examine the expiry of a temporary area.
- The human tests of Phase 12 (the server shell), of tasks 065 to 084, and of 0.1.0-rc.10 to 0.1.0-rc.13 stay open. The desktop part of the human test of task 086 passed on 2026-11-03.
