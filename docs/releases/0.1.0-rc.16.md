# Music Index Studio 0.1.0-rc.16

This candidate is the first with the desktop app "Music Index Studio" ([ADR 0124](../adr/0124-the-desktop-app-is-a-tauri-window-on-the-local-api.md)). The app opens Studio in its own window, and it has installers. It comes after 0.1.0-rc.15.

## What changed

### The desktop app

- The app opens Studio in its own window, with no browser and no address to copy.
- When you close the window, Studio stays in the tray. A connected app can continue to write under a show grant. **Open Studio** in the tray shows the window again.
- **Quit** in the tray waits for a write or an upload that runs. It shows a dialog with three buttons: **Quit After Write**, **Quit Now** and **Cancel**. While the app waits, the tray menu shows "Quits after the write…".
- A link to a different site opens in your browser. A download goes to your Downloads folder, and a dialog names the file.
- A second start shows the window of the first start. Only one app or one `studio-desktop` at a time can use a data folder.
- The app uses the data folder of `studio-desktop`. Your collection, your vault and your library stay.

### The installers

- The GitHub Release has nine installers. These are an AppImage, a DEB and an RPM for each Linux system, a DMG for each macOS system and an MSI for Windows. The five archives stay.
- The installers have no code signature. The notes below this text tell you how to open the app on macOS and on Windows.
- `SHA256SUMS.txt` lists all 14 files.

### The archive

- `studio-desktop` uses port 42069. When that port is in use, it uses a free port for that start.
- The theme and the settings of the UI stay between starts on port 42069.

## What to test

Do these steps on your Linux computer.

1. Install the DEB or the RPM of your system, or run the AppImage.
2. Start Music Index Studio. Make sure that the window shows your collection.
3. Change the theme. Quit the app from the tray and start it again. Make sure that the theme stays.
4. Close the window. Make sure that the tray icon stays. Select **Open Studio** in the tray.
5. Drag a music file from your file manager onto the file field of a track. Make sure that Studio receives the file.
6. Start a write to a file host on the internet, and select **Quit** in the tray. Make sure that the dialog shows. Select **Quit After Write**. Make sure that the app ends after the write.

## Known gaps

- The test of an install over an earlier version needs the next candidate.
- The macOS and Windows installers need a tester with that system.
- On Linux with no D-Bus session, a second start shows "Studio is already running." and does not show the first window.
- The human tests of Phase 12 (the server shell), of tasks 065 to 084 and of 0.1.0-rc.10 to 0.1.0-rc.15 stay open.
- The server part of the human test of task 086 stays open.
