# Music Index Studio 0.1.0-rc.25

This candidate corrects the upload fault that the test of rc.24 found. It also adds the role curator. It has no new database schema version. Rc.24 and this candidate use schema version 43.

## What changed

### Files

- **Fix:** an upload continues after the unlock of the vault. Before, Studio asked for the unlock when the vault was locked, and then the upload stopped with the error "upload ID" not found. The upload of a feed on a file host with a secret had this fault.
- **Fix:** the state text of an import row wraps in its card. When an import stops with an error, a long ID or a long address in the text can break on a new line.

### Publisher feeds

- **New:** Studio knows the role curator. The left panel gives a curator feed the heading "Curators". A curator has its own color, from the musicindex design tokens. The Role menu does not change.
