# Music Index Studio 0.1.0-rc.30

This candidate makes it easier to add releases and pages. You can start a new release from a feed that is on Music Index. The desktop app can also open without the passphrase on your own computer.

## What's new

- **＋ Add** is one menu on Releases and on each artist, label and hosting page: **Release**, **Artist**, **Label**, **Show** and **Playlist**.
- Each add form starts with **Find on Music Index**. Select a result to copy its title, artwork, tracks and payment recipients into the new release. Studio copies no audio file. Before the first write, examine **Value Routes** (the payment shares of the release).
- A new release starts with its artist page. Review writes the release and its artist page together.
- In the left panel, each group below an open page ends with an add row, for example **＋ Add release**. After you make a release or a page, the left panel goes back to where you made it.
- A release row shows “Artist: {name}” when the artist of the release is not the name of the page. When an artist page does not list one of its releases, **Issues** of the release tells you and offers **Write {page}…**.
- A click on a row with the mark “Not checked” starts its check.
- **Move This Release…**, **Follow the Move** and a discard of a move keep **Media files** correct. **Library files** does not show the same file two times.
- A deleted release shows **Put the File Back** and **Check Again** on each tab. A delete also removes the empty folders on local and SFTP file hosts.
- **Send the Podping Again** shows when a podping fails. A podping tells podcast apps that a feed changed.
- Desktop app: **Settings** > **Lock** > **At start** has **Unlock on this computer**. Studio then keeps a key in the keyring of your computer, and the vault opens at the start with no passphrase. On Linux, this needs a keyring service such as GNOME Keyring or KeePassXC.
- The sort menu has **Page Order** and **Page Order, Reversed**.

## Try this

1. Start Studio on your collection. Make sure that Releases and People show your feeds and persons.
2. On Releases, select **＋ Add** > **Release**. Select **Find on Music Index**, and search for a release. Select a result, and make sure that the form tells what it copies. Make the release, and examine Review before you write. If this is only a test, select **Remove from Collection…** in Review.
3. In the left panel, select your artist page. Select **＋ Add release** at the end of the group Releases. Make sure that the new release shows below your artist page.
4. Write a change to a release with “Send a podping” on. Make sure that the write completes.
5. If you have two file hosts: select **Move This Release…** on a test release, then **Add to the Draft**, then discard the draft. Make sure that **Media files** shows the first file host again.
6. Desktop app: in **Settings** > **Lock**, set **At start** to **Unlock on this computer**. Quit Studio, and start it again. Make sure that Studio opens with no unlock screen.

Tell us each step that did not work, and what the screen showed.

## Known problems

- With KeePassXC, an access request shows at each start of Studio. Select **Allow Selected**. To stop the request, turn off “Confirm when passwords are retrieved by clients” in the KeePassXC settings for Secret Service. Then each app of your user account can read the entries that KeePassXC shares.
- On a narrow screen, the release rows below an artist page do not show “Artist: {name}” or the warning that the page does not list the release. **Issues** of the release shows it.
- A release that was written before this version shows no artist name and no warning until its next write.
- The search of Music Index does not mark your own feeds. When you select one of your feeds, Studio adds it with no copy.
- A release that Music Index has no title for shows only its ID in the search.
- Review scrolls slowly in the desktop app with a long draft.
- In a new iPhone Safari tab, a back swipe before the first touch opens the first page of Studio.
