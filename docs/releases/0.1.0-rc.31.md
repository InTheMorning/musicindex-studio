# Music Index Studio 0.1.0-rc.31

This candidate is for persons who host other artists and labels. A release, an artist page or a label page can move below different pages. On a server, you can sign out from the left panel. On the desktop app, you can change to a different collection from the left panel.

## What's new

- **＋ Add** on Releases has **Hosting** after **Label**. A hosting page is for a person who hosts the music of other artists and labels. The Welcome page has the row “I'm hosting for other artists”.
- A hosting page shows the groups Labels and Artists. A label page shows Artists and Releases. Only an artist page has **＋ Add release**, so each new release starts on the page of its artist.
- In the Artist, Label and Hosting forms, **Find on Music Index** can start the new page from a release. The Artist form takes the artist name, the website and the payment recipients of that release. The new page links the release.
- A release in “Not linked” has **Move To…**. The section “Linked artist and label pages” of a release also has **Move To…**. Select an artist page, and optionally a label page and a hosting page. Then **Move** links the release to these pages.
- An artist page and a label page also have **Move To…**, in the page head and in the **⋯** menu of their row. The sheet shows each release that changes. A hosting page has no **Move To…**.
- Server: **File hosts** > **＋ Add a File Host** has “Temporary area (7 days)” when your account has no temporary area.
- Server: **Sign Out** is at the bottom of the left panel.
- Desktop app: the bottom of the left panel has **Switch Collection…**. With two or more collections, the row shows “Collection: {name}”. A click opens a list of your collections, with **Open** on each other collection and **Manage Collections…** for Settings.

## Try this

1. On Releases, select **＋ Add** > **Hosting**, and make a test hosting page. Make sure that the page shows the groups Labels and Artists, each with its add row.
2. Open a release in “Not linked”, or make a test release. Select **Move To…**, select an artist page, and select **Move**. Make sure that the release shows below that artist page. Examine Review before you write.
3. Open a test artist page. Select **Move To…** in its head, and select a label page. Make sure that the sheet tells which releases change. Select **Move**, and make sure that the artist page shows below the label page.
4. In the Artist form, select **Find on Music Index**, and then a release. Make sure that the form tells what it takes from the release. If this is only a test, do not write the new page.
5. Server: select **File hosts** > **＋ Add a File Host**. Make sure that “Temporary area (7 days)” is in the type menu when your account has no temporary area.
6. Server, on a phone and on a computer: select **Sign Out** at the bottom of the left panel. Make sure that Studio shows the sign-in page.
7. Desktop app: select **Switch Collection…** at the bottom of the left panel. Select **Manage Collections…** and make a test collection. Then select its row at the bottom of the left panel, and **Open** your first collection again.

Tell us each step that did not work, and what the screen showed.

## Known problems

- If Studio stops during **Move**, some releases can keep their earlier pages. Select **Move To…** again to complete the move.
- With KeePassXC, an access request shows at each start of Studio and at each change of collection. Select **Allow Selected**. To stop the request, turn off “Confirm when passwords are retrieved by clients” in the KeePassXC settings for Secret Service. Then each app of your user account can read the entries that KeePassXC shares.
- On a narrow screen, the release rows below an artist page do not show “Artist: {name}” or the warning that the page does not list the release. **Issues** of the release shows it.
- The search of Music Index does not mark your own feeds. When you select one of your feeds, Studio adds it with no copy.
- A release that Music Index has no title for shows only its ID in the search.
- Review scrolls slowly in the desktop app with a long draft.
- In a new iPhone Safari tab, a back swipe before the first touch opens the first page of Studio.
