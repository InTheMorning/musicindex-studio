# Music Index Studio 0.1.0-rc.32

This candidate is for persons who host other artists and labels, and for each person who keeps a feed GUID. A move of many releases now has one review and one write. Review repairs addresses that are not full and offers the values of People. Studio stops each change of a feed GUID until you type the feed title.

## What's new

- **Move To…** and **Move** now open one review of all the feeds that change. The change set also shows in People > **Changes to write**. When a feed is read-only or is in an open change set, the message names the feed.
- On a hosting page and a label page, the add row of Artists has **Move Artists Here…**. On a hosting page, the add row of Labels has **Move Labels Here…**. The sheet moves many pages below the page in one change set.
- When you add a file host, Studio now looks 6 folders down and reads a maximum of 5000 files. Then the File hosts page names each feed of that host that stays read-only. **Add a File Host for Them** helps you add the file host of these feeds.
- **Use the LNURL Address** of a wallet lists only the feeds that change. The sheet tells how many feeds pay the address already.
- An address with no `https://`, such as `www.example.com`, gives a Stop on the tab **Issues** and in Review. **Add https://** repairs it. The write stays off until the repair.
- Review tells when the credits or the payees of a feed are different from People. **Use the People Values in {n} Feeds** puts the People values in the drafts.
- In Review, a set of equal changes shows as one line, with the name of each entry in one fold.
- A link from an artist page to a release with an old GUID gives a Warning on the tab **Issues**. **Use the GUID of {title}** corrects the link.
- A fee value of `true`, `1` or `yes` is a fee. Each other value is not a fee. An unknown value gives a Warning on the tab **Issues**.
- **The feed GUID.** Studio keeps the GUID that it knows for each feed. Other music feeds pay a feed by its GUID, so a change stops those payments.
    - When a write changes the GUID, Review shows a Stop. **Write to the File Host** stays off until you type the feed title. **Keep the Old GUID** puts the GUID back.
    - When the hosted file gets a different GUID outside Studio, the tab **Issues** shows a Warning. Select **Put Back** or **Keep the New GUID**.
    - A move with **Replace the File** over a feed with a different GUID gives the same Stop.
    - Before the first write of a new feed, Studio asks Music Index about the address. When Music Index has a different feed there, Review shows the same Stop.
    - When you add a feed by its address, and the collection has that address with a different GUID, Studio adds nothing and tells you.

## Try this

1. Open some of your releases, and select **Review**. Make sure that Review shows no GUID panel when you did not change the GUID.
2. Open the tab **Issues** of some releases. Make sure that no release shows "The GUID changed outside Studio" when its GUID did not change.
3. On a hosting page, select **Move Artists Here…**. Select one test artist page, and select **Move**. Make sure that one review opens with each feed that changes. Then select **Discard**.
4. Open a test release. Put `www.example.com` in an information address of a credit. Make sure that Review shows the address panel, and that **Add https://** repairs it. Discard the draft after the test.
5. On **File hosts**, add a file host for a folder of your feeds. If a feed of that folder stays read-only, make sure that the page names it.

Tell us each step that did not work, and what the screen showed.

## Known problems

- When you make a page from the **Move Artists Here…** sheet, the page stays after **Discard**. Remove it from the collection when you do not need it.
- Before the first write of a new feed, Studio waits for the answer of Music Index. Other changes wait during that time.
- The GUID of an episode or a track has no Stop. A merge or a restored version can change it.
- With KeePassXC, an access request shows at each start of Studio and at each change of collection. Select **Allow Selected**. To stop the request, turn off “Confirm when passwords are retrieved by clients” in the KeePassXC settings for Secret Service. Then each app of your user account can read the entries that KeePassXC shares.
- On a narrow screen, the release rows below an artist page do not show “Artist: {name}” or the warning that the page does not list the release. **Issues** of the release shows it.
- The search of Music Index does not mark your own feeds. When you select one of your feeds, Studio adds it with no copy.
- Review scrolls slowly in the desktop app with a long draft.
- In a new iPhone Safari tab, a back swipe before the first touch opens the first page of Studio.
