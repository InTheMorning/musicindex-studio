# Music Index Studio 0.1.0-rc.33

This candidate is for artists, labels and persons who host other artists. Studio starts on Overview, and the left panel shows your artists, labels and publishers as a tree. Each release has the fields Artist, Label and Publisher. You can sign an artist to a label, or move a page in the tree, with music words and one Review.

## What's new

- **Overview** is the start page. It shows your releases below the name of each label and each artist, and your playlists below each curator. "Independent" holds the releases with no label. The search finds a release by its title or by the name of its artist, label or curator.
- **The Catalog.** The left panel shows your publishers, labels and artists as a tree. The **⋯** menu of an artist has **Sign to a label…**, **Change label…**, **Go independent…**, **Choose a publisher…** and **Change publisher…**. Each sheet shows the label or publisher before and after the change, and lists the releases that change.
    - In the sheets of a label or a publisher, **＋ Make a new label page** and **＋ Make a new publisher page** make the page. The sheet then shows again, with the new page selected.
    - On a desktop window, drag a row by its handle to a different label or publisher.
    - After a change, a notice shows the new label or publisher, with **Undo**. The top bar shows "{N} changes not written" and **Review**. One Review writes each feed that changes.
- A page or a release with no publisher page is "self-published". Examples: "Independent, self-published" and "On Harbor Records, self-published".
- **A release has one artist, one label and one publisher.** The first tab of a release has the fields Artist, Label and Publisher. Each field has **New … Page…** to make a page.
- Each link has its own roles. On a page, each release has its own role check boxes, for example Label and Publisher.
- Review of a page or of a release also writes the other feed of a changed link. The check box "Also write {title}" shows each of these feeds.
- Review warns you before you write a release with no track and no payment split: "Music Index does not list {title}". You can write it and add the tracks after.
- A release with an artist link that has no role gets **Make It the Artist Link**.
- A feed with a misspelled or missing `podcast:medium` tag gets the menu "Type of this feed" and **Review the Change**.
- A playlist shows below each page that its `curator` link names.
- The release list of a page keeps the sequence of the feed file. **Move up**, **Move down** and **Move to the top** change it.
- Each feed that Studio changes names Studio in its `generator` tag.
- A click that is not on an open **⋯** menu closes the menu. Each row "Find on Music Index" has a search icon. In Retire, **Check Again** shows the time of the check.

## Try this

1. Start Studio. Make sure that Overview shows each of your releases one time, below the correct label and artist.
2. In the left panel, open the **⋯** menu of a test artist. Select **Sign to a label…**, then **＋ Make a new label page**. Make a test label, and select **Sign**. Make sure that the top bar shows the count and **Review**. Then select **Undo** in the notice.
3. Open a release. Make sure that the fields Artist, Label and Publisher show its pages.
4. Open a page with many releases. Select **Move up** on one release. Make sure that Review shows the new sequence. Then discard the draft.

Tell us each step that gave an incorrect result, and what the screen showed.

## Known problems

- When you make a page from a sheet, the page stays after **Undo** or **Discard**. Remove it from the collection if it is not necessary.
- In Retire, Music Index can keep a hidden feed after the podping. Then step 2 does not complete.
- A feed in Retire continues to show in the label and publisher lists of the sheets.
- At 390 px width, the top bar can be on top of the field "Description" of a publisher page when you scroll.
- Drag and drop is not available in a narrow window. Use the **⋯** menu.
- KeePassXC asks for access at each start of Studio and at each change of collection. Select **Allow Selected**.
- Review scrolls slowly in the desktop app with a long draft.
- In a new iPhone Safari tab, a back swipe before the first touch opens the first page of Studio.
