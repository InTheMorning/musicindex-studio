# Checks Of 0.1.0-rc.31 For The Operator

The [notes of 0.1.0-rc.31](../releases/0.1.0-rc.31.md) are for testers who are not the operator. This file has the full list of changes with their ADRs, the steps on the operator's data and the known gaps for the operator ([ADR 0236](../adr/0236-the-release-notes-are-for-testers-and-the-operator-checks-are-in-a-review-file.md) item 6). [The checks of rc.30](2026-11-21-rc30-checks.md) give the steps of rc.30.

The database schema version does not change.

## What changed

### Releases and pages

- **New:** **＋ Add** of Releases has **Hosting** after **Label**. The Welcome page has “I'm hosting for other artists”. A hosting page shows Labels and Artists. A label page shows Artists and Releases. Only an artist page has **＋ Add release** ([ADR 0240](../adr/0240-hosting-is-a-first-role-and-a-stray-release-moves-to-its-pages.md) items 1 to 8).
- **New:** a release in “Not linked” and the section “Linked artist and label pages” have **Move To…**. **Move** links the release to the selected pages, and removes its links to other pages of these roles (ADR 0240 items 9 to 19).
- **New:** an artist page and a label page have **Move To…** in the head and in the **⋯** menu of their row. A release row also has the **⋯** menu. The move changes the links of each release of the page (ADR 0240 items 20 to 25).
- **New:** in the Artist, Label and Hosting forms, a found release makes a page of the role of the form, with no tracks. The new page links the release ([ADR 0238](../adr/0238-a-found-release-gives-the-page-of-each-role.md)).
- **Fix:** the **＋ Add** menu of an empty release list opens to the right.

### File hosts (server)

- **New:** **＋ Add a File Host** has “Temporary area (7 days)” when the account has no temporary area (task 226, [ADR 0122](../adr/0122-a-new-user-starts-with-a-default-file-host.md) items 3 and 9).
- **Fix:** the address of a temporary area no longer gives the error 422 “the temporary area is only on a server”.
- **Fix:** step 2 of the Welcome sheet has no temporary row when the account has the temporary area.

### The left panel

- **New:** on a server, **Sign Out** is after the lock row ([ADR 0241](../adr/0241-sign-out-and-switch-collection-are-rows-of-the-panel-footer.md) items 1 to 3).
- **New:** on the desktop app, one collection row opens the sheet “Switch Collection”. With one collection, the row is “Switch Collection…”. With more, it is “Collection: {name}”. The sheet has **Open** on each other collection and **Manage Collections…** ([ADR 0242](../adr/0242-the-collection-row-of-the-footer-opens-switch-collection.md), ADR 0241 items 5 to 8).

## What to test

The tests and the screenshots of each change passed. [The desktop human check of ADR 0241 and ADR 0242](2026-11-21-adr-0241-human-check.md) passed on the operator's data. The steps that follow need the deploy or the operator's data.

### Server

1. Open the public server on a computer. Select **File hosts** > **＋ Add a File Host**. If the account has no temporary area, make sure that “Temporary area (7 days)” is the first type. If it has one, make sure that the type is not in the menu.
2. On the iPhone, open the public server and sign in. Make sure that **Sign Out** is the last row of the root page. Select it, and make sure that Studio shows the sign-in page.

### Desktop app

3. Make a test hosting page with **＋ Add** > **Hosting**. Make sure that it shows Labels and Artists with their add rows. Remove it from the collection after the check.
4. Move a test release to a different artist page with **Move To…**. Examine Review, then discard the draft.
5. Move a test artist page below a label page with **Move To…** in its head. Make sure that the sheet lists the releases. Discard the drafts after the check.

### Steps that stay open from earlier candidates

6. The steps of [the checks of rc.30](2026-11-21-rc30-checks.md) that are not complete stay open.

## Known gaps

- The move route does each check before the first write, but it writes each link separately. The collection has no transaction for many links. If Studio stops during a move, some releases can keep their earlier links.
- Before a move, Studio saves only the draft of the moved feed. The move can change the draft of an open release with unsaved edits.
- KeePassXC asks at each start of Studio and at each change to a collection with a keyring key.
- The other gaps of [the checks of rc.30](2026-11-21-rc30-checks.md) stay.
