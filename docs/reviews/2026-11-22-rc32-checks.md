# Checks Of 0.1.0-rc.32 For The Operator

The [notes of 0.1.0-rc.32](../releases/0.1.0-rc.32.md) are for testers who are not the operator. This file has the full list of changes with their ADRs, the steps on the operator's data and the known gaps for the operator ([ADR 0236](../adr/0236-the-release-notes-are-for-testers-and-the-operator-checks-are-in-a-review-file.md) item 6). [The checks of rc.31](2026-11-21-rc31-checks.md) give the steps of rc.31.

The database schema version changes from 50 to 52. Migration 51 adds the table `change_set_kept_levels` (ADR 0243). Migration 52 adds `feeds.known_guid` and fills it from `podcast_guid` when the GUID is not a placeholder (ADR 0249 item 1). An older Studio cannot open the collection after this candidate opens it.

## What changed

### Moves and change sets

- **New:** a move of a release or a page makes one change set and opens its review. The change set shows in People > **Changes to write**. A refusal names each read-only feed and each feed in an open change set ([ADR 0243](../adr/0243-a-move-is-a-change-set-and-a-level-gathers-its-pages.md) items 1 to 6, tasks 229 and 230).
- **New:** the add rows of a hosting level and a label level have **Move Artists Here…** and **Move Labels Here…**. The sheet moves many pages below the level page (ADR 0243 items 7 to 11).
- **New:** a list of a connector goes 6 folders down and stops at 5000 files. After a new file host, the page names each read-only feed of that host that the match did not find. It has **Add a File Host for Them** (ADR 0243 items 13 to 15, task 231).
- **Fix:** the sheet of **Use the LNURL Address** lists only the feeds with a node recipient of the wallet (ADR 0243 item 16, task 232).
- **Fix:** the form of a new hosting page has no Type menu.

### Review and People

- **New:** the finding `short_address` (Stop) and the repair **Add https://**. The review of one feed and of a change set has the address panel. The write stays off until the repair. The `bad_address` refusal names each field by its place ([ADR 0245](../adr/0245-review-repairs-short-addresses-and-offers-the-people-values.md), tasks 233 to 235).
- **New:** People refuses an address that is not correct. A review gives the feeds that differ from People, with **Use the People Values in {n} Feeds** (ADR 0245 items 9 to 12, [ADR 0246](../adr/0246-a-link-with-no-medium-equal-changes-in-review-and-the-people-button.md)).
- **New:** a set of equal changes in a review gives one summary line and one closed fold (ADR 0246).
- **Fix:** a channel link with no `medium` is a release link when it names a music feed of the collection. Thus the links of `elijahliedpubfeed.xml` now give roles (ADR 0246, task 236).
- **Fix:** the fee value follows musicindex ADR 0093. An unknown value gives the Warning `unknown_fee` ([ADR 0244](../adr/0244-studio-reads-the-fee-value-of-musicindex-adr-0088.md)).

### The feed GUID

- **New:** the Warning `link_guid_old` with **Use the GUID of {title}** for a link with an old `feedGuid` and a correct `feedUrl`. **Move Artists Here…** corrects these links ([ADR 0247](../adr/0247-studio-restores-a-changed-feed-guid-and-corrects-a-link-with-an-old-guid.md) items 7 to 9, task 237). [ADR 0248](../adr/0248-music-index-changes-a-feed-guid-in-place-and-studio-restores-no-guid.md) removes the restore of ADR 0247 items 1 to 6.
- **New:** the known GUID of each feed. A write that changes the GUID stops until the feed title is typed. A grant write cannot change the GUID ([ADR 0249](../adr/0249-studio-strongly-discourages-a-feed-guid-change.md) items 1 to 5, task 238).
- **New:** the Warning `guid_changed_outside` with **Put Back** and **Keep the New GUID** (ADR 0249 items 6 and 7, task 239).
- **New:** the same Stop for a move with **Replace the File** over a different GUID, and for a new feed at an address where Music Index has a different feed (`GET /v1/feeds/by-url`). The add by address gives a notice for an address of the collection with a different GUID. A 404 answer with `superseded_by` gives the Warning `index_guid_changed` (ADR 0249 items 8 to 11, task 240).

## What to test

The tests and the screenshots of each change passed on the test data in `.studio-dev/v-230`. The steps that follow need the operator's data, the release binary or the deploy.

### Desktop app, on the operator's data

1. Start the rc.32 desktop app. It changes the collection to schema 52. Make sure that Studio opens with no error.
2. Open five releases, and select **Review** on each. Make sure that no Review shows a GUID panel. A panel here is a false Stop of migration 52 or of item 2 of ADR 0249.
3. Open the tab **Issues** of the Elijah Lied releases. Make sure that no release shows "The GUID changed outside Studio". If one shows it, record the two GUIDs. Do not select a button.
4. On a hosting page, select **Move Artists Here…** and one artist page. Make sure that one review opens. Select **Discard**, and make sure that the links are as before.

### Server, after the deploy

5. Open the public server on a computer. Open one release and select **Review**. Make sure that Review shows no GUID panel.

### Steps that stay open from earlier candidates

6. Steps 3 to 5 of [the checks of rc.31](2026-11-21-rc31-checks.md) stay open. The steps of [the checks of rc.30](2026-11-21-rc30-checks.md) that are not complete stay open.

## Known gaps

- The by-url read of ADR 0249 item 9 sends its request while Studio holds the workspace lock. It runs only for a feed that Studio did not read or write before (operator choice in task 240).
- Other reads do not follow `superseded_by` (ADR 0248 and ADR 0249, Open Questions). The data of the operator and of TJ is not examined for changed GUIDs.
- The item GUIDs have no Stop. A merge or a restored version can change them (ADR 0249, Open Questions).
- A page that the user made from the sheet of **Move Artists Here…** stays after **Discard** (ADR 0243, Consequences).
- The person page does not offer **Correct the Feeds** at once after a save of a new value (ADR 0245, Consequences).
- The other gaps of [the checks of rc.31](2026-11-21-rc31-checks.md) stay.
