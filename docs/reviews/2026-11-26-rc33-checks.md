# Checks Of 0.1.0-rc.33 For The Operator

The [notes of 0.1.0-rc.33](../releases/0.1.0-rc.33.md) are for testers who are not the operator. This file has the full list of changes with their ADRs, the steps on the operator's data and the known gaps for the operator ([ADR 0236](../adr/0236-the-release-notes-are-for-testers-and-the-operator-checks-are-in-a-review-file.md) item 6). [The checks of rc.32](2026-11-22-rc32-checks.md) give the steps of rc.32.

The database schema version changes from 52 to 53. Migration 53 adds the tables `catalog_steps`, `catalog_step_feeds` and `catalog_step_kept_levels` for the Undo steps of the Catalog ([ADR 0254](../adr/0254-the-catalog-is-a-tree-and-each-change-uses-music-words.md), packet 251b). An older Studio cannot open the collection after this candidate opens it.

## What changed

### Feed type, links and roles

- **New:** a feed with a bad or missing `podcast:medium` tag gets the menu "Type of this feed" and **Review the Change** ([ADR 0250](../adr/0250-studio-corrects-the-type-of-a-feed-with-a-bad-or-missing-medium-tag.md), task 241).
- **Fix:** **Find Other Feeds** of a host runs again, and the match uses the GUID (23e3e2b, task 246).
- **New:** Review of a page or of a release also writes the other feed of a changed link, with the check box "Also write {title}". Review stops when a linked release has no other page ([ADR 0251](../adr/0251-review-writes-the-two-sides-of-a-changed-link.md), tasks 242 to 245, 249).
- **New:** a release link with no role gets **Make It the Artist Link** ([ADR 0252](../adr/0252-a-publisher-link-with-no-role-gets-a-repair.md), task 247).
- **New:** each link has its own roles. The role hosting shows as Publisher. A release on a page has its own role check boxes ([ADR 0253](../adr/0253-the-roles-of-a-feed-and-of-each-link.md), tasks 250, 253 and 255).

### Catalog and release fields

- **New:** the Catalog tree in the left panel. The **⋯** menu has **Sign to a label…**, **Change label…**, **Go independent…**, **Choose a publisher…** and **Change publisher…**. A desktop window has drag and drop from a handle. Each change goes into one change set with Undo (ADR 0254, tasks 251, 253 and 254).
- **New:** the fields Artist, Label and Publisher of a release, each with **New … Page…** ([ADR 0257](../adr/0257-a-release-has-one-artist-one-label-and-one-publisher-in-its-fields.md), task 252).
- **New:** "self-published", the group "New" in the label and publisher sheets, the button **Sign**, one **Review** in the top bar. Review warns "Music Index does not list {title}" for a music feed with no item and no payment split ([ADR 0267](../adr/0267-a-page-sheet-can-make-a-new-page-and-review-has-one-button.md), task 260).

### Overview, sequence and playlists

- **New:** Overview is the start page, with "Search the collection" ([ADR 0263](../adr/0263-overview-is-the-start-page-and-each-page-keeps-the-sequence-of-its-feed.md), task 256).
- **New:** Overview headings by label, artist and curator, with tiles ([ADR 0264](../adr/0264-overview-groups-the-releases-below-label-artist-and-curator-headings.md), task 256).
- **New:** the release list of a page keeps the sequence of its feed, with **Move up**, **Move down** and **Move to the top** (ADR 0263, packet 256d).
- **New:** a playlist shows below each page that its `curator` link names ([ADR 0266](../adr/0266-a-playlist-shows-below-each-page-that-its-curator-link-names.md), task 258).
- **New:** each feed that Studio changes names Studio in its `generator` tag ([ADR 0265](../adr/0265-a-changed-feed-names-studio-as-its-generator.md), task 257).

### Fixes from the walk of 2026-11-26

- **Fix:** a click that is not on an open menu closes it. The retire condition of a feed made in Studio comes from the written copy. **Check Again** shows "Checked at {time}". The row "Find on Music Index" has a search icon. The drag has a top drop area (task 259).
- **Fix:** Undo keeps the server keys, and the notice of an external change shows immediately (feb17e8, 74efa28).

## What to test

The tests and the screenshots of each change passed on the test data of the harnesses in `.studio-dev`. The human check of ADR 0267 passed (656d567). The steps that follow need the operator's data, the release binary or the deploy.

### Desktop app, on the operator's data

1. Start the rc.33 desktop app. It changes the collection to schema 53. Make sure that Studio opens on Overview with no error.
2. Make sure that Overview shows each release one time, below the correct label and artist headings.
3. Open five releases. Make sure that the fields Artist, Label and Publisher show the correct pages, and that **Review** gives no unexpected Stop.
4. In the Catalog, open the **⋯** menu of one artist, select **Change label…** and a different label. Make sure that the top bar shows the count and **Review**. Select **Undo** in the notice, and make sure that the count goes.

### Server, after the deploy

5. Open the public server on a computer and on the iPhone. Make sure that Overview and the Catalog tree show. Open one release and select **Review**. Make sure that Review shows no Stop.

### Steps that stay open

6. Step 4 items 2 to 5 of [the walk of 2026-11-26](2026-11-26-human-check-walk.md) (task 254), and the task 254 sheet in Light and Dark.
7. Steps 5 to 8 of task 256, which include task 258.
8. The retire of TestLabel. It waits for the deploy of stophammer ff9bb60 and stophammer-crawler 79bcc74.
9. The steps of [the checks of rc.32](2026-11-22-rc32-checks.md) that are not complete stay open.

## Known gaps

- A page that the user makes from a sheet stays after **Undo** or **Discard**. The check of task 260 showed this gap.
- Retire step 2 does not complete while Music Index keeps a hidden feed. The Stophammer deploy is necessary.
- Finding 13 of the walk of 2026-11-26: the sign sheet lists a label in Retire. No change until the operator decides.
- At 390 px, the top bar is on top of the field "Description" of a publisher page after a scroll. This gap was in rc.32.
- Drag and drop is not available at 760 px or less (ADR 0254 item 10).
- The other gaps of [the checks of rc.32](2026-11-22-rc32-checks.md) stay.
