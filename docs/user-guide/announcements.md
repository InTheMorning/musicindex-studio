# Announcements

After you write a feed, Studio can tell the Podcast Index hub about the change.
The hub is the Podcast Index service that lists feeds.

## Choose for each write

In Review, select **Send a podping**. A change set uses **Tell Podcast Index and send a podping**.

Studio remembers your last choice for the next write. The box is on until you change it.
Studio usually sends the podping 30 seconds after the write. A return can delay it until after Music Index’s waiting time.

Clear the box when you save frequently and do not want to announce each save. An index then learns about the write only when it reads the feed by itself.

A write under a show grant always announces, because a live show needs it.

## See the announcement in the review

The Review footer shows the podping choice or its cause, such as **No podping: this feed has no public address.**

## See the state of the last announcement

1. Open the album.
2. Open **Feed facts** on the album page.
3. Read the line **Announcement**.

The line shows one of these states:

- Waiting. Studio tells you when it sends the announcement.
- Sent. Studio shows the time.
- Failed. Studio shows the time and the error.
- "No announcement yet."

If an announcement fails, Studio tries again at the time that it shows. It also shows the last error.

The notice after a write shows whether Music Index has read the feed. Select **Send the Podping Again** when a podping fails. Select **Check Again** to check the feed again. Select **Dismiss** to remove the notice.
