# Delete a Feed File

Studio can retire a feed before it deletes the feed file. A retire asks Music Index to remove the entry.
Studio cannot examine Podcast Index. The entry can keep its last payment recipients after the file is gone.

## Open the options

1. Open the feed. Go to the section **Feed** on the release page.
2. Select **Delete from File Host…**. A sheet opens.
   - Select **Put the feed on a different file host** to move it.
   - Select **Take the feed out of the apps** to retire it.
   - **Remove the file** shows only when Studio confirms that removal can proceed.

## Retire the feed

Studio shows three steps in the section **Feed**. It reads Music Index when this page opens and when you select **Check Again**.
Keep the feed address after you remove the file. A different address does not give the entry back.

1. Review and write the change that hides the feed from apps.
2. Select **Check Again** to read the current answer from Music Index.
3. When Music Index removes the entry, select **Delete the File**.

Wait until Studio confirms removal before you select **Delete the File**. Select **Stop Retiring** to turn off the hide switch in the draft.
Review and write that change through the usual write flow.

## Delete the file

The delete sheet names the file host and path. It lists the files that Studio deletes and keeps.
Select **Also delete the audio and image files** to include those files in the draft.
Studio keeps pointer files and files that a different feed uses.

Type the feed title in the field. Type the same text as the title.
If the feed has no title, type its file name.
Select **Delete** to open Review. Examine the diff and write it to remove the file.
Select **Cancel**, close the sheet, or press Escape to discard the delete draft.

After the write, Studio keeps the feed in the collection as read-only.
Select **Put the File Back**, examine Review, then write the draft to put the file back.
