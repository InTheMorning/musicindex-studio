# Check a feed

The tab **Check** shows what Studio finds in a feed. It is before **Settings** on the page of a feed.
The tab shows the number of findings, for example **Check 5**. With no finding, the tab shows **Check**.

Studio does not change the feed when it checks it. Nothing changes until you select a button.

## Read the findings

Each finding is one row. The row has a level, a title, a cause and one button.

- **Notice**. Studio found a problem. The button repairs it, or opens the field where you repair it.
- **Question**. Studio needs a value from you. The button opens the field.

A row has no button when Studio cannot repair the finding. A read-only feed has no file host. Studio shows its findings and does not repair them.

When Studio cannot read an address, the page says "Studio could not read this address." and gives the address.

## Select a button

- **Add the Link** and **Use the Public Address** put the public address in the self link. Studio first reads the public address. It changes the draft only when the feed there is this feed.
- **Use the https Address** changes an `http` address to its `https` address. Studio changes it only when the `https` address gives the same file.
- **Read the Size** reads the size of an audio file from its host and puts it in the track.
- **Open the Track** opens the page of the track.
- **Select a Language** opens the field **Language** in **Settings**.

Each change goes to the draft. Open **Review** to see it. The feed file changes only when you write the draft.
If you do not want a change, change the field again, or discard the draft.

If a feed has a show grant, a granted change waits while the draft has changes. The page tells you this.

## Check Again

Studio reads the addresses of the feed when you open the tab. Select **Check Again** to read them again.
Use it after you change a file on a host, or when Studio could not read an address.
