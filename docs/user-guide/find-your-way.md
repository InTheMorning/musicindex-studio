# Find and open a release

## The pages of Studio

Studio has a left panel with these entries:

- **Releases**
- Each artist feed, label feed or other feed with roles, with the number of its releases
- **Not linked**, when a release has no artist or label
- **Hosts** (at the bottom)
- **Settings** (at the bottom)
- **Lock Studio** (at the bottom, when the vault is open)
- **Unlock Studio** (at the bottom, on a server with a locked vault)

Studio starts on **Releases**.

## The Releases page

The page lists each album and each playlist in your collection.
Each row shows the cover, the title, the type and the host.
A feed with no host shows "Read-only".
The row also tells you the draft state:

- "New, not written"
- "Saved, not written"
- "No changes"

To open a release, select its row.

### Sort and view

- Select the sort button, then select **Newest** or **A to Z**. With **A to Z**, a row of letters lets you jump to a group.
- Select **Rows** or **Tiles** to change the view.

Studio remembers the sort and the view in the address of the page.

### An empty collection

If you have no feeds, the page shows "No releases yet."
Select **Add a Feed**. See [Add feeds that you already have](add-feeds.md).

## The releases of an artist or a label

Select an artist feed or a label feed in the left panel. The page shows its releases.
The line below the title shows each role of the feed.

The sort is **Feed order** at first. This is the sequence of the releases in the feed. You can also select **Newest** or **A to Z**.

A release of two feeds shows on the page of each feed. The row names the other feed, for example "Also on Some Label".
Select **Open the feed** to edit the artist feed or the label feed.

**Not linked** lists the releases that have no artist or label in your collection.
To add a link, see [Artist and label feeds](artist-and-label-feeds.md).

## The outline of a release

When you open a release, the left panel shows its outline.
The outline lists the pages of the release.

For an album, the outline has these entries:

- **Album**
- One entry for each track
- **Add tracks**
- The live shows, and **Add a live show**
- **Value routes**
- **Credits and links**
- **Files**

An artist feed has **Artist** and **Files**. A label feed has **Label** and **Files**.
A playlist has **Playlist**, **Tracks**, **Value routes** and **Files**.
A read-only feed has one page, **Feed**.

Select **Releases** at the top of the outline to go back to the list.

## The toolbar

For an editable feed, the toolbar stays at the top of the page.
It shows the draft state, the button **Versions** and the button **Review**.

| Draft status | Meaning |
| --- | --- |
| Loading… | Studio loads the draft. |
| Saving… | Studio saves your changes. |
| Saved, not written | The draft has changes that you did not write. |
| No changes | The draft is the same as the hosted file. |
| Not saved | Studio could not save the draft. |

See [Review and write your changes](review-and-write.md).

The back and forward buttons are at the left of the title.
They move through the pages that you opened.

## A narrow window

When the window is 760 pixels wide or less, Studio shows one page at a time. It opens on **Releases**.
Select the back button to go to the first page.
The first page lists **Releases**, each artist and label, **Hosts**, **Settings** and **Lock Studio**. On a server with a locked vault, it shows **Unlock Studio**, not **Lock Studio**.
When you open a release, you see its outline first. Select a page in the outline to open it.
Use the back button to go back.

## Changes in the library folder

Studio can find a difference between the library folder and its records.
For example, you change an image file with a different tool.
Studio then shows "Studio found N changes in the library folder."
Select **Show** to open the **Files** page of the first release. See [Manage the files of a release](release-files.md).
A small mark on a release shows that its folder changed.

## Light and dark theme

Use the sun and moon button in the left panel to change the theme.

## Your account on a server

On a server, the Settings page has the panel **Account**.
Use it to add a passkey, to sign out and to delete the account.
See [Your account on a server](account.md).

To open Studio from the home screen of a phone, see [Add Studio to the home screen](home-screen-app.md).
