# Add Studio to the home screen

You can put Studio on the home screen of a phone.
Studio then opens like an app, with no browser bar. Its name on the home screen is "Studio".

## On an iPhone

1. Open the address of the Studio server in Safari.
2. Select the share button.
3. Select **Add to Home Screen**.
4. Select **Add**.

## On an Android phone

1. Open the address of the Studio server in Chrome.
2. Open the menu of the browser.
3. Select **Add to Home screen** or **Install app**.
4. Follow the steps of the browser.

## What changes

Studio works as in the browser. The sign-in and the unlock do not change.
Studio needs a network connection. With no connection, Studio shows an error.
