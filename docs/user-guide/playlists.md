# Playlists

A playlist is a feed that lists tracks from other feeds.
Studio keeps only the links to the tracks. It does not copy the audio.

## Make a playlist

You need a host with a public address. See [Connect a host](hosts.md).

1. Select **Releases** in the left panel. Then select **＋ Add a feed**.
2. On the page **Add feeds**, select **Playlist** in the group **Make a new feed**. A sheet opens.
3. Select the host in **Host** if you have more than one.
4. Type the name in **Playlist name**.
5. Type the author in **Author**.
6. Select **Make the playlist**.

Studio gives the feed file from the name. To change it, open the row **Feed file**.

Studio opens the playlist as a draft.
Write it to make the file. See [Review and write your changes](review-and-write.md).

## The pages of a playlist

The outline of a playlist has these pages:

- **Playlist**. Fields: **Title**, **Author**, **Description**, **Cover image address** (with **Choose…**), **Website** and **Language**. **Feed facts** is also on this page.
- **Tracks**
- **Value routes**. See [Value routes](value-routes.md).
- **Files**. See [Manage the files of a release](release-files.md).

## Add tracks

1. Open **Tracks**.
2. Select **Add a track**. The sheet "Add tracks" opens.
3. Select where the tracks come from:
   - **Search musicindex**. Type a name, select **Search**, then open a feed to see its tracks.
   - **My releases**. Studio lists the tracks in your collection, grouped by feed.
4. Select **Add** on the line of a track. A track that is in the playlist shows "In the playlist".
5. Select **Done**.

The sheet stays open after each **Add**, so you can add many tracks.

## Change the playlist

On the page **Tracks**, each track has a position menu and the button **Remove**. Select a number in the menu to move the track to that position.
The page also shows a summary of the tracks.

Then write the playlist. See [Review and write your changes](review-and-write.md).
