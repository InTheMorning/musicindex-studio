# Use Studio from a phone

You can change a feed from a phone when you use Studio on a server.
Open the address of the server in the browser of the phone, and sign in. See [Sign in to a Studio server](sign-in.md).

## Sign in on a phone

These methods are easy on a phone:

- **Sign in with a passkey**. Add the passkey before, in the Account panel. See [Your account on a server](account.md).
- **Sign in with Amber or a bunker**. Select **Open in the signer app** to open your signer app on the same phone.

## One page at a time

On a phone, Studio shows one page at a time. It opens on **Releases**.
Select the back button to go to the first page.
The first page lists **Releases**, each artist and label, **Hosts**, **Settings**, and **Lock Studio** or **Unlock Studio**.
When you open a release, you see its outline first. Select a page in the outline to open it.
Use the back button to go back.
See [Find and open a release](find-your-way.md).

## Unlock the vault

On a server, the vault can be locked while you work.
When a step needs a secret, Studio shows the sheet **Unlock Studio**.
Unlock with your passphrase, your signer or your passkey. Then Studio continues the step.
See [Passphrase, unlock and lock](vault.md).

## Send music files

Studio sends each music file in parts.
If the connection stops, Studio tries each failed part again.
If the page closes, select the same file again. Studio continues the upload.
See [Add, import and change tracks](tracks.md).

## Sign with the signer on your phone

A host with **My signer** needs a signature for each write.
If the browser has no signer extension, the review sheet shows **Connect a signer**.
Connect Amber or a bunker as for a sign-in. Then select **Write to the host**.
See [Review and write your changes](review-and-write.md).
